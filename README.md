# MySpace – Personal Profile Web Application

CSC584 Enterprise Programming individual assignment.

## Description
A Java web application that allows students to enter their personal and academic details and view them as a profile.

## Technologies
- Java 8
- Java EE 7 (Servlet 3.1 and JSP)
- HTML5 and CSS3
- NetBeans IDE 8.2
- GlassFish Server 4.1.1

## Main Features
- Personal information form
- Student ID, programme and email details
- Self-introduction and hobby selection
- Profile result page

## Run the Project
1. Clone or download this repository.
2. Open the project in NetBeans IDE 8.2.
3. Select GlassFish Server 4.1.1.
4. Run the project.
